Detailed Description

Generic temporal filter with confidence-scaled convergence and smoothstep S-curve dropout decay.

Designed for signals that require smooth tracking during active sampling and graceful, non-penalizing decay during brief dropouts (e.g. tracking priors, orientation hints).

Dual-regime dynamics:

  1. Active Sampling (has_sample == true): Filters values with exponential smoothing whose effective time constant scales inversely with confidence: tau_eff = base_tau_track / confidence. High confidence gives rapid convergence; low confidence dampens jitter.
  2. Dropout Decay (has_sample == false): Holds the last valid state over a configurable grace window (hold_window_s) with zero initial rate of change (w'(0) = 0). Beyond the hold window, smoothly accelerates and decelerates decay towards the neutral baseline along a cubic Hermite smoothstep S-curve (w(t) = 1 - 3t^2 + 2t^3) over decay_window_s.
