Detailed Description

Second-order inertial dwell / charge accumulator node for gaze UI interactions.

Smoothly charges fill in [0.0, 1.0] toward 1.0 when target_error <= 0 (or active_target is true) and drains toward 0.0 when outside the target, accelerating rate changes via fill_acceleration and drain_acceleration and scaling drain acceleration with (1 + error / error_doubling_distance).

Configure fill_sec / drain_sec (or fill_rate / drain_rate) and choose automatic updates via process_callback (PROCESS_MANUAL, PROCESS_IDLE, or PROCESS_PHYSICS), or call process_error_delta() / process_dwell_delta() manually.

Signals emitted: fill_changed(fill: float), fill_started(), filled(), emptied().
